# 维护文档与验证记录

安装和常规使用从[仓库首页](../README.md)开始；Agent 的生产规则位于[Skill 入口](../skills/jjf-external-deck/SKILL.md)。

| 文档 | 用途 |
|---|---|
| [PUBLISHING.md](PUBLISHING.md) | 更新现有仓库、版本同步、发布检查及首次建库 |
| [VERIFICATION.md](VERIFICATION.md) | 当前检查的范围、命令、实际结果与未验证项 |
| [PRIVACY.md](PRIVACY.md) | 公开分发边界和私有材料处理 |
| [SKILL-REVIEW.md](SKILL-REVIEW.md) | 各次修订的审查依据和历史记录 |
| [verification-report.json](verification-report.json) | 带发行版本的机器可读验证摘要 |
| [core-test-results.txt](core-test-results.txt) | Skill 核心测试输出 |
| [publication-test-results.txt](publication-test-results.txt) | 仓库发布与版本一致性测试输出 |

当前版本以根目录 [VERSION](../VERSION) 为准，历史版本说明保留在 [CHANGELOG.md](../CHANGELOG.md)。测试通过只证明相应本地检查，不能代替实际图片转换、Canva 导入和视觉验收。
