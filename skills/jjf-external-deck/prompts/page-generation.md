# 单页执行提示词模板

为JJF对外宣传Deck制作【page_id/page_number/topic_key】的一张16:9页面。

【锁定正文】
逐字使用content-lock里本页visible_text；保留required_content，主题不能变。证据缺口不自行补数字。

【品牌】
读取brand-tokens。用用户官方Logo文件【path/hash】独立贴入；不重画Logo。深炭黑、白字、JJF绿重点，现代无衬线，中英文层级清楚。

【本页任务】
主结论：【thesis】
视觉家族：【family】；构图：【layout】；唯一主物件：【motif】。
前页：【前页视觉摘要】；后页：【后页视觉摘要】。要保持品牌但不重复主物件与构图。
文字密度：【density】。密集页背景必须安静；留出明确正文区域。
参考图：【1—2张，说明只参考构图/气氛，不采用其数字/Logo/案例事实】。

【资产生成】
优先只生成主视觉或不带字的干净背景，再排准确文本与Logo；不可把真实案例、团队身份或建成空间交给模型捏造。整页直出时，按图片优先路线检查中文与Logo后再交付。

【禁止】
白米色地产模板；办公室黑T恤白板重复；满屏发光卡片；随机英文墙贴；无依据数据；普通JJF替代正式Logo；串到其他页主题；一个文件多页拼图；向用户输出两份不同风格的“正式/分析”稿。

【输出】
仅当前页一个可验收候选，明确返回文件路径、实际像素尺寸、生成/设计方式、仍有问题。主agent检查后再决定展示。使用工具真实支持的参数，不在用户可见文字输出工具JSON。
