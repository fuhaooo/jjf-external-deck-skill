# 官方 Logo 选择

下列 SVG 按用户提供的官方物料原字节复制，未重绘或矢量化。来源与 SHA256 见 `provenance.json`。

| 文件 | 用途 | 注意 |
|---|---|---|
| `jjf-logo-primary.svg` | 默认图标：封面、页眉、Canva | 绿色圆角底、白色多线JJF、原有阴影；源文件 `jjf-v2.svg` |
| `jjf-logo-white.svg` | 深色照片/深色背景上的单色水印或角标 | 透明底；2048×2048画布含原生留白，不是紧裁字形 |
| `jjf-logo-white-on-black.svg` | 明确需要黑色底块的单色物料 | 黑底不透明，不能冒充透明标 |
| `jjf-logo-master.png` | 不支持SVG或SVG效果异常时兼容 | 保留原2048×2048 RGBA，不能换成缩略图 |
| `jjf-logo-icon.png` | Skill列表小图标 | 不作为大屏高清主资产 |

全套默认使用primary，不随页混用变体。用户指定“以第二页为准”时，先读取其实际官方资产和文字规格；参考若是错误/生成标识，只参考排版并换用官方标志，不传播错误字形。

英文“AI Craft Labs”和下方“中国·厦门 JJF AI 造物实验室”不包含在图标中。优先用原生文本统一字形、字重、颜色及基线；绿色只强调Labs，JJF前缀以项目确认的参考为准。品牌文字转成轮廓/图片后须说明其为整体可缩放组件、不能逐字编辑；用户要求逐字编辑时不能用该方式替代。

未收录另一品牌ougin、含嵌入位图的jjf_logo.svg、同字节重复的jjf-logo-common.svg，以及场地照片、二维码、压缩包和周边角色图，它们不是通用Deck页眉的必要资产。
