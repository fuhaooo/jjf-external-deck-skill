# 已有 Canva 的局部修订

用于“修第12页”“第3页以后品牌区按第2页统一”“截图后直接调整”等已有可编辑设计任务。用户明确要求修改指定原设计时，本路线取代新制Deck默认新建副本；不要求导出、重新拆解或重建整套。

## 范围与参考组件

从会话已确认链接/ID读取原设计、实际页序、页ID和对象，印刷页号另记。仅缺目标定位时询问信息，不重新申请已有编辑授权。保存修改前快照，需要时创建备份；最终交付仍指向用户指定原设计。

沿用已给出的“直接调整、保存、自动纠错、按某页统一”等授权，记录依据，不冒称用户逐项批准。确定的识别错误可按原图/文字锁修正并记录改前/改后；数字、机构名、政策和存在争议的原稿措辞不能凭猜测重写。平台自身实际要求的批准仍须满足。

用户指定第2页时，记录该页图标资产ID/哈希、原生文字、字体/字重、颜色片段、尺寸、坐标、英文与中文基线、间距和透明度。`brand-tokens.json`的header_lockup只是默认值，不能压过明确参考。核对每页对应对象：单独Labs框、合并中英文框、旧底块和重复字形；不得按大范围坐标盲删背景。

优先用官方SVG和原生字标。缺少字体、片段颜色或文字插入能力时，不能声称精确匹配。字标转轮廓/图片须披露逐字编辑限制；用户要求逐字编辑时保留原生方案或明确能力阻塞。只统一用户选中的页，不顺带修改封面、正文或页序。

## 编辑、保存与续跑

1. 读取当前工具schema后打开事务。事务ID短期有效，不把旧ID当持久状态；保留对象基线、预期操作、逐项结果和保存检查点。
2. 先验证一个代表页的真实预览。格式/宽度调整可能引起位置漂移，最终定位最后执行；根据实际渲染高度校准字号，不混用像素、磅和变换后的文字尺寸。schema要求整数时不能传小数字号。
3. 检查每项结果：批量可能部分成功。文本框可能只支持改宽、不支持改高，个别框横向也不能调整。按真实错误改变方法，只重试未成功项。
4. 图片非等比改宽高可能改变裁切而非缩放。保持比例并看预览；恢复清晰素材使用原资产ID/原文件，不能用200px缩略图代替原素材。
5. 逐页检查重叠、换行、层级、Logo净空和正文边界。已授权直接修正的任务，展示预览后在范围内自行验收和保存，不再添加逐页确认。
6. 确认commit成功，再回读原设计与页面。若事务失效，先读取当前保存状态，再计算尚未落盘差异；不能盲目重放insert产生重复Logo。保留范围内可恢复的结果，不把草稿或过期预览当已保存成品。

持久记录不包含凭据或临时签名上传地址；用户项目的私有设计链接不进入公开Skill仓库。

## 验收与能力边界

- 比较前后页数、页序、页ID和非目标对象的文字、位置、大小、资产。仅换第3页后品牌区时，第1—2页及目标页正文应无差异；出现差异逐项解释。
- 每个目标页记录组件资产与几何，保存逐页预览/对照，防止只修一页却声称全套统一。放大600px预览不等于高清验收，不能据此宣称像素级保真。
- 缺少图层排序、局部文字颜色或原生插字等能力时，不破坏其他合格对象掩盖限制；报告已保存内容与具体未还原位置。
- 确需单页替换且已有授权时，先准备该页和备份。工具若一次只接受一个页操作，先插入、回读确认新旧页ID和页数，再移除确认的旧页；不得按过期页码删除。遵守实际工具的删除审批要求，其余页保持原状。

本路线可直接记录 `editing → saved → canva-verified`，不需要伪造PPTX转换阶段。
